ELITES NEWS WEBSITE
====================

FILES
-----
index.html        Main homepage
article.html      Individual article page
style.css         Complete website styling
script.js         News data, search and interactions
backend/elites_news.c   C news-management prototype

HOW TO RUN
----------
1. Extract the ELITES_News folder.
2. Open index.html in Chrome, Edge or Firefox.
3. Click news articles to open article.html.
4. Use the search box and navigation menu.

C PROGRAM
---------
Open backend/elites_news.c in Code::Blocks.
Build and Run it.

IMPORTANT
---------
The C program is a learning/admin prototype. A production news website
normally uses a web backend and database. The sample website currently
uses JavaScript data so it can run immediately without a server.

To publish the site, upload the HTML, CSS and JS files to a web host.
Replace the sample stories with verified real news and properly licensed
images before publishing.
